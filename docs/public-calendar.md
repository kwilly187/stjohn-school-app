# Public dates in My Students

My Students shows a limited upcoming public schedule, not a student's attendance, enrollment or verified class calendar. It reads the same school-published Activities source as the native Calendar and applies conservative grade/schoolwide rules. Grade- or sport-specific dates appear in the configured presentation demo only when they match explicit public information. A successful retrieval does not guarantee that school staff have reviewed every event or that it cannot change.

Dates without a clear schoolwide or matching scope stay in the wider Calendar. No dismissal time is invented for date-only early release. An unavailable feed is not an empty schedule; use the official school calendar as a fallback. See [native Calendar](native-calendar.md) and [source ownership](content-ownership.md).

There are no fictional announcement routes or authenticated student records. Private notices, assignments and grades stay with the school's existing sign-in and authorization.
