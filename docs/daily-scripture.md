# Daily Scripture

Home shows a curated seven-reading rotation from the public-domain World English Bible Classic. Verse text and the publisher's public-domain statement were verified November 14, 2026 at:
- https://ebible.org/eng-web/PSA023.htm
- https://ebible.org/eng-web/PSA118.htm
- https://ebible.org/eng-web/webfaq.htm

Line breaks are collapsed to spaces; wording is unchanged. Each reading links to the full chapter. This is not represented as the school's selected devotion, lectionary, or a live third-party daily feed. No generated reflection or prayer is included. The separate school-approved devotion contract remains unchanged and unpopulated.

Selection uses America/New_York calendar dates. The server supplies a consistent hydration timestamp; mounted clients refresh each minute and when tab visibility changes. No remote API, secret, or network request is required to display the stored Scripture. School handoff should confirm its preferred Bible translation and selected reading schedule.

Tests cover source attribution, daily selection, DST and mounted-tab refresh/cleanup.
